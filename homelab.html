Section 2 · Done

Active Directory

Goal: every staff member gets their own login, sorted by department.

Problems I hit
  • Locked out after setup. The password was rejected, so I rebuilt the server.
  • 169.254 address. This meant no static IP, so I set it before going on.
  • Wrong server name. I renamed it before installing Active Directory.
  • Extra folder wouldn't delete. It was protected, so I turned that off first.
What I learned

Habits I now follow

  • Save a snapshot before every big change.
  • Test a new password straight away.
  • Check the name and IP before installing anything.
