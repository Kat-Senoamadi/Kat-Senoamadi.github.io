Problems I hit, and how I fixed them

Pings failed even though the IP settings were right

Clue: "Destination host unreachable", with replies coming from the server itself. Cause: the virtual network was still on its default range (10.0.2.0/24). Fix: shut the server down, corrected the range, re-tested: 0% loss. Lesson: check the device, then the network, and read the actual ping reply.

Locked out after promoting the domain controller

Clue: the domain existed but the password was rejected. Checks: ruled out Caps Lock and keyboard issues with the on-screen keyboard. Fix: no recovery path, so I rebuilt the server. Lesson: test credentials straight after setting them, and snapshot before big changes.

The server showed a 169.254 address

Cause: an APIPA address means the PC couldn't get an IP, so no static IP had been set. Fix: set it before installing AD, because a domain controller needs a fixed address.

A duplicate OU wouldn't delete

Cause: OUs are protected from accidental deletion by default. Fix: turned on Advanced Features, removed the protection, deleted only the duplicate.

Habits I now follow

  • Take a VM snapshot before every major change
  • Test a new password by signing out and back in, then record it
  • Check the computer name and IP before installing any server role

How I handle a problem

A real case, written up as a ticket

CASE · Customer service floorResolved · Escalated
Issue

A customer called for the third time. Two earlier agents had not solved their problem, and they were frustrated.

What I did

I read the case history to see what had already been tried, so the customer didn't have to repeat themselves. Every standard fix had already been done. This needed a higher level.

Escalation

I took it to my team leader and we escalated it for urgent attention, with the full history attached.

Outcome

The customer thanked me for taking ownership and rated the call highly.

Lesson

Check what's been done first. Know the limit of your level. Escalate early with good notes. This is exactly how a Level 1 helpdesk works.
